# Image provenance and use

These assets were newly generated for the aivideoweb.com team's open-source prompt collection on 2026-10-21. There are **12 images: 1 cover and 11 recipe previews**. No external gallery images or reference screenshots were used.

The generator was the **built-in imagegen tool**. Its exact underlying model identifier was not exposed. These assets are **not Nano Banana 2.1 test outputs**. All target-model tests remain pending.

`generation-manifest.json` records original prompts, local paths, dimensions, SHA-256 hashes, generator disclosure and visual-review notes. All source prompts are available for reproduction, but generation is stochastic and a repeated prompt may produce a different image.

The project grants permission to reuse its supplied image files to the extent it has rights to do so. Generated imagery may have no exclusive copyright protection and can contain errors; no third-party clearance, exclusivity or suitability warranty is made. The repository MIT license applies to original text and code and does not create rights in third-party marks, people or reference materials.

Only optimized WebP delivery files are committed. No image was copied from a third-party prompt collection. Previews are illustrations of selected recipes rather than evidence that every instruction was obeyed. Review observed limitations in the manifest.
