**48 个原创场景 · 12 个实用分类 · 完整中英双语提示词 · 4 种语言的项目介绍**

## 五分钟使用流程

1. 在[中文目录](prompts/zh.md)选场景；同一 ID 的中文和英文是同一条内容，不重复计算数量。
2. 替换虚构主体、材质、配色与准确文案。保留与任务相关的构图限制。
3. 在工具中选择 Nano Banana 2.1，并设置画幅、分辨率。提示词中写“4K”不等于已经设置输出参数。
4. 编辑类先上传获授权参考图，清楚标注哪张定义主体、哪张只参考布局或配色。
5. 先做小图，按验收点检查；每轮只改一个问题。人物或产品漂移时，从原始参考图重新开始。

```text
用途：咖啡新品海报。
主体：透明杯中的冰橙咖啡，细小冷凝水珠。
构图：珊瑚橙背景，上方标题，下方单行副标题。
准确文字："ORANGE HOUR"；"A brighter coffee break"。
保留：独立冰块、真实玻璃、清楚文字。
避免：额外文案、价格、无关物件与水印。
验收：检查拼写、玻璃透视和杯底接触阴影。
```

更多操作见[模型与编辑指南](docs/model-guide.md)；多语言文字排版见[本地化手册](docs/localization.md)。

## 为什么围绕 Nano Banana 2.1 细化？

项目目标型号为 `gemini-nano-banana-2.1`。版本能力与核实日期见[官方资料说明](docs/model-guide.md)。我们把短句精确排版、参考图职责、角色稳定特征和单点修正写进提示词，方便在目标模型中逐条验证。

这些是制作方法，不是“百分百准确文字”“像素级一致”或“无需后期”的保证。界面图只是视觉概念，游戏纹理不保证无缝，科普示意图也需要内容审核。

## 原创内容与透明记录

每条都有独立制作目标：例如背包放大窗口必须对应原物，角色工具袋不能左右镜像，海报翻译不改变日期价格。新图不使用外部项目图片，也不把更换品牌名当作原创改造。

结构化数据保留稳定 ID、目标模型、实测状态、参考图要求和展示图路径。所有展示图的真实生成工具单独记录。内容更新看[更新日志](CHANGELOG.md)，写作和发布标准看[编辑清单](docs/editorial-checklist.md)。

## 常见问题

### 免费吗？

原创文本与代码采用仓库现有的 [MIT 许可证](LICENSE)，阅读和复制不收费。具体图片服务可能单独收费。

### 支持几种语言？

48 条提示词全部有中文与英文版本；另有日语、西语项目介绍与入门示例。不能把入门说明说成完整翻译目录。多语言扩展可依据[本地化手册](docs/localization.md)提交。

### 能商用吗？

文本与代码许可见 MIT；生成图片并不附带独占性或第三方权利清理保证。图片的用途和生成来源见[图片说明](assets/README.md)，使用时应核对模型服务条款和参考素材授权。

### 为什么不是每条都配图？

当前展示图覆盖部分文生图场景。未配图条目提供制作方案，尚未附带视觉结果；编辑类没有伪造输入照片或效果对比。覆盖范围以生成记录为准。

### 能保证不会被认为是抄袭吗？

不能做这种保证。实际做法是独立设计场景、重新撰写表达、重新生成图片、记录来源并接受纠错。若后续贡献引用了第三方内容，必须保留适用许可要求的署名，不能通过删除署名规避义务。
