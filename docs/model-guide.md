# Nano Banana 2.1：模型与编辑指南

维护者：[aivideoweb.com](https://aivideoweb.com) · 核实日期：2026-10-21

## 先确认使用的版本

本项目面向 `gemini-nano-banana-2.1`。Google 的[官方型号页面](https://ai.google.dev/gemini-api/docs/models/gemini-nano-banana-2.1)记录了该型号的图片生成与对话编辑能力，支持 1K、2K、4K 输出，并描述了文字排版、多参考图和连续编辑方面的改进。型号页最近更新于 2026-10-06。实际入口、参数和可用能力应以你使用的客户端为准。

本仓库尚未在该型号上运行案例，也不提供价格、速度或成功率结论。目标型号与展示图生成器是两个不同字段，不应混写。

## 把能力变成可检查的任务

以下是本项目的编辑建议，不是模型官方性能指标：

| 任务 | 提示词怎么写 | 验收怎么做 |
|---|---|---|
| 标题排版 | 给出短句、准确大小写、位置和行数 | 放大检查每个字母、标点与漏字 |
| 角色连续性 | 明确衣服、道具、左右位置与每格动作 | 对比各格脸型、配色、道具数量 |
| 产品保真 | 将产品图标为身份依据，背景图只提供布局 | 对比轮廓、标签、接口和材质 |
| 多图融合 | 每张参考图只负责一个明确维度 | 分别核对身份、布局和色调 |
| 长幅设计 | 明确两端内容与中央留白，客户端设置比例 | 检查接缝、重复主体和裁切 |
| 信息图 | 限制节点数量、标签和连接方向 | 将图中结构与文字需求逐项比对 |

## 一个可复用的提示词结构

```text
用途：这张图最终放在哪里？
主体：一个明确对象，写出辨认它的关键特征。
场景：背景、表面、材质和光线。
构图：主体位置、留白、视角与层级。
文字：逐字给出要出现的文案；没有文字就写明。
参考图职责：图1定义主体；图2只参考布局；图3只参考色调。
必须保持：本轮不能变化的元素。
本轮只改：一个需要修正的问题。
验收：一个能明确判断是否通过的检查点。
```

不要把所有风格词塞进一条提示词。先解决主体、构图和文字，再根据需要添加镜头或材质描述。

## 分辨率和画幅不是魔法词

在生成工具的控件或 API 配置中设置尺寸、比例与可用选项。提示词写“4K”“16:9”只是在表达创作意图，不保证客户端采用该设置。本库的 `aspect_ratio` 是推荐值，不是自动生效的 API 参数。

先用低成本草稿检查结构。结构不对时放大分辨率通常不能补救；先修正构图，再生成交付尺寸。

## 多图与连续编辑

1. 检查参考图权限，避免混入无关物件或品牌。
2. 按上传顺序编号，并写出每张图的职责。不要假定模型知道哪一张是产品图。
3. 先建立一个可接受的基准结果，记录本次提示词、实际型号和设置。
4. 每轮限定一个改动，重复列出必须保持的内容。
5. 发生明显身份漂移时，从原始参考图重新开始，避免不断修补已经变形的版本。

```text
只把外套颜色改为深海军蓝。
保持面部、发型、皮肤、身体比例、姿态、背景、衣服材质和褶皱不变。
保持金属拉链原色。不要新增任何文字。
```

## 常见问题与修正

| 问题 | 下一轮可以怎么说 |
|---|---|
| 标题拼写错误 | 只修正标题为指定短句，逐字保留，其他部分不变 |
| 多了一件产品 | 恰好保留指定数量，删除额外物件并补全原背景 |
| 角色左右道具反了 | 工具袋位于角色自身左侧，不能按观看者左侧判断 |
| 透明玻璃像塑料 | 保留玻璃边缘折射和低对比透光，不增加白色实体描边 |
| 信息图箭头乱连 | 明确写出起点→终点，减少交叉线，先用少节点版本 |
| 海报翻译后变形 | 只在原文字框内调整字号和换行，保持图形与网格不变 |
| UI文字过多 | 保留少数标题和按钮，完整界面用设计或开发工具实现 |

## 如何提交真实模型测试

提供条目 ID、实际服务返回的型号、生成日期、客户端或接口、完整提示词、比例、分辨率、参考图职责、原始输出和已知偏差。不得只根据界面上的营销名称推断底层型号。

一次成功输出也不代表稳定成功率。若做对比，需要说明每个模型的运行次数、筛选标准和是否做过人工修改。
